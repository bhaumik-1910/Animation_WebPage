# 🎨 Animation Web Page

Animation Web Page is a creative and visually engaging frontend project built using **HTML, CSS, and JavaScript**.  
It demonstrates animations, transitions, and interactive UI elements that enhance user experience and frontend design skills.

---

## 🌟 Features

- ✨ Smooth CSS animations  
- 🖼️ Interactive elements  
- 🎨 Stylish hover effects  
- 📱 Responsive layout  
- 🧠 Great for UI & animation practice

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **VS Code Live Server**



---

## ⚙️ Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/bhaumik-1910/Animation_WebPage.git
cd Animation_WebPage
```

### 2️⃣ Run the project
Open index.html in your browser
```bash
Right Click on index.html → Open with Live Server
```
